Claude Code — CLI
Instalação via terminal · global ou por projeto
1

Baixe o bundle .zip

Use o link acima e extraia em qualquer pasta temporária.

2

Crie a pasta de skills

Global: ~/.claude/skills/
Local: .claude/skills/ na raiz do projeto.

3

Extraia cada .skill

Cada arquivo .skill é um zip. Extraia na pasta de skills — cada skill vira uma subpasta com SKILL.md.

4

Use no terminal

Dentro de uma sessão claude, digite /skills para ver a lista.

Instalação Global — macOS / Linux

Skills disponíveis em qualquer projeto no seu computador.

# 1. Crie a pasta global de skills
mkdir -p ~/.claude/skills

# 2. Entre na pasta onde estão os arquivos .skill
cd ~/Downloads   # ajuste conforme onde salvou

# 3. Extraia todos os 10 skills de uma vez
for f in *.skill; do
  unzip -o "$f" -d ~/.claude/skills/
done

# 4. Confirme
ls ~/.claude/skills/

Instalação Global — Windows (PowerShell)

# 1. Crie a pasta global de skills
New-Item -ItemType Directory -Force `
  -Path "$env:USERPROFILE\.claude\skills"

# 2. Entre na pasta onde estão os arquivos .skill
Set-Location "$env:USERPROFILE\Downloads"

# 3. Extraia todos os 10 skills
Get-ChildItem *.skill | ForEach-Object {
  Expand-Archive -Path $_.FullName `
    -DestinationPath "$env:USERPROFILE\.claude\skills" -Force
}

# 4. Confirme
Get-ChildItem "$env:USERPROFILE\.claude\skills"
